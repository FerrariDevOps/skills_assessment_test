# Skills used in this repository

This folder documents, rather than vendors, the Claude Code skills relevant to how this repository was put together. Each entry is a short reference stub, a `SKILL.md` with the skill's name, purpose, and a link to its full source, not a copy of the actual skill files.

## Anthropic skills

From the official [anthropics/skills](https://github.com/anthropics/skills) catalogue, the ones actually relevant to a documentation and Terraform repository like this one.

- [doc-coauthoring](doc-coauthoring/SKILL.md), used to draft and refine each scenario's answer
- [skill-creator](skill-creator/SKILL.md), the meta skill for building and maintaining skills like the ones in this folder

## Community skills

There is no single official standard for community skills, the ecosystem has tens of thousands of entries across independent lists. These two are illustrative examples that fit this repository's content, not an endorsed standard.

- [terraform-skill](terraform-skill/SKILL.md), by [antonbabenko](https://github.com/antonbabenko/terraform-skill)
- [markdown-linter-fixer](markdown-linter-fixer/SKILL.md), by [s2005](https://github.com/s2005/markdown-linter-fixer-skill)
